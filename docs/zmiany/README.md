# Zmiany w kodzie

Jeden plik na zmianę, **nazwa pliku od zmiany** (nie od daty ani numeru) —
np. `backend-sc4hub.md`, `walidacja-obszaru-roboczego.md`.

Opis zwięzły: 1–3 zdania o co chodzi, lista zmienionych plików z jednolinijkowym
komentarzem, ewentualne uwagi o ryzyku lub rzeczach do zweryfikowania.
Bez diffów. Szablon i pełna konwencja: [`../../CLAUDE.md`](../../CLAUDE.md).

Na razie pusto — nie wprowadzono jeszcze zmian w kodzie.
