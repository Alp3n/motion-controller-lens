========================================================================
    SFoundation Library : HTML Help Reference
========================================================================

This zip file contains a standalone copy of the SFoundation HTML help reference manual for 
ClearPath-SC motors.  

The ClearPath-SC software foundation, or "sFoundation", is a C++ object-oriented, motion 
control class library. This library provides you with a variety of functions used to interface
with, and control your ClearPath-SC integrated servo motor.

Sometimes the content of the help reference manual file type is blocked by security settings. 
If this occurs you can try the following:

	-Right Click the extracted S-FoundationRef.chm file and select Properties -> Security and 
	check the Unblock check box where it says "This file came from another computer and might 
	be blocked to protect this computer."
	
	- If you are still unable to see the content of the reference, install the ClearView motor
	setup program https://teknic.com/files/downloads/ClearView_Install.zip
		Once installed, you should be able to find a link to the help reference here: 
		C:\Program Files (x86)\Teknic\ClearView\sdk
